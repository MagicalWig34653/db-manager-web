  `#/db/<db>[/schema/<s>]/tabelle/<t>[/<tab>]`. Ungültige Hashes führen zur Startansicht (SQL). Die URL enthält nur
  Objektnamen und Reiterkennungen, nie Zugangsdaten, Token oder SQL. Eine Tabellenroute wird erst nach geladenem
